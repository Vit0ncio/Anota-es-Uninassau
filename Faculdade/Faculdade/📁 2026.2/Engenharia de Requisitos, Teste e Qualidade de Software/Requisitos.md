# Tipos de Requisito


* **Requisito Funcional:** Descreve o que o sistema deve fazer;

* **Requisito não Funcional:** Não depende do que o sistema deve fazer. Exemplos:

	* Desempenho,
	* Segurança;

* **Requisito do Cliente:** É uma necessidade do usuário que vai utilizar o sistema.

* **Requisito do Sistema:** É uma necessidade do sistema. Geralmente um requisito mais técnico.

* **Regra de Negócio:** São necessidades da empresa.

# Exemplos:

1. "O sistema deve processar e carregar a tela inicial em menos de 2 segundos" -> Requisito não Funcional

2. "O sistema deve permitir que o cliente adicione e remove produtos de um carrinho" -> Requisito de Usuário/Funcional

3. "Nossa empresa fornece frete grátis em compras superiores a R$ 200,00" -> Regra de Negócio

# Exercícios:

1. "A farmácia concede 20% de desconto no balcão exclusivamente para clientes acima de 60 anos" -> Regra de Negócio

2. "O sistema deve enviar um email com o comprovante em pdf assim que o pagamento foi aprovado" -> Requisito Funcional

3. "O tempo de busca por produtos no catálogo não deve ultrapassar 2 segundos, mesmo durante picos de acesso" -> Requisito não Funcional

4. "O cliente deseja acompanhar o trajeto do entregador do restaurante em tempo real" -> Requisito do Cliente

5. "O sistema deve consultar a API do GPS a cada 5 segundos para atualizar a posição da entrega na tela" -> Requisito do Sistema

6. "Todas as senhas e dados de cartão de crédito gravados no banco de dados devem ser criptografados" -> Requisito Funcional

7. "A clínica veterinária não aceita pagamentos em cheque para consultas de emergência" -> Regra de Negócio

8. "O sistema deve permitir que o administrador bloqueie temporariamente o acesso de um usuário específico" -> Requisito Funcional/de Sistema

9. "O portal de matrículas deve suportar até 5000 acertos simultâneos sem queda do servidor" -> Requisito não Funcional
